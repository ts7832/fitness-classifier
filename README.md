# Fitness Classification Project

This project provides a machine learning-based solution for classifying individuals as "Fit" or "Not Fit" based on health and lifestyle data. It includes data analysis, model training and evaluation, and a user-friendly web interface for making predictions.

## Documentation

- [Exploratory Data Analysis Results](docs/data-analysis.md):
	- Summarizes the main findings from the exploratory data analysis (EDA), including data cleaning, attribute distributions, and key insights about the dataset.
- [Model Evaluation Report](docs/model-evaluation.md):
	- Details the model training, validation, and testing process. Includes a comparison of different models, evaluation metrics, and the final selected model's performance.
- [User Interface Guide](docs/user-interface.md):
	- Explains how to use the Gradio-based web interface, including descriptions of all input fields, model selection, and tips for reliable predictions.
